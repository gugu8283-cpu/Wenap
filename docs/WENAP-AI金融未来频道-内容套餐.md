# AI 金融未来频道 · 长短视频混合套餐

> **频道核心：** AI × 金融 × 未来 — 未来科技金融媒体，不是新闻搬运号  
> **平台：** YouTube + TikTok 为主；小红书可复用 Shorts 截图版  
> **产品：** 片尾 **固定 5 秒** Wenap（A/B/C 档），前面零产品  
> **口令：** `套餐 + {话题}` → AI 按本文生成本期套餐清单 + 各条脚本骨架  

---

## 一、两条铁律（每条片都遵守）

| 铁律 | 规则 |
|------|------|
| **广告** | 最后 **5 秒** 只提 Wenap + 免责；时长固定，不拉长 |
| **内容型号** | 每条片定 **1 个主型号**（讨论 / 解释 / 展望）；可掺另外两种，但气质以主型号为准 |

**主型号判定：** Hook 问的那句话属于哪类，就是哪类。

| 主型号 | Hook 问法 | 片尾 Wenap 档 |
|--------|-----------|---------------|
| 讨论型 | 这件事意味着什么？ | **B**（讲了具体股）/ **C**（没讲股） |
| 解释型 | 这到底是什么？ | **C** |
| 展望型 | 未来会怎样？ | **C** |

**片尾 5 秒文案（CapCut 文字层）：**

- **C 档（默认）：** `Wenap · wenap.app` + `非投资建议 / Not financial advice`
- **B 档（讨论 + 有 ticker）：** 口播一句「完整报告在 wenap.app」+ 同上文字
- **A 档（讨论 + 已展示 App 截图）：** 仅 Logo + 域名 + 免责，口播可省

## 二、什么是「套餐」

**1 个套餐 = 1 个热点主题 → 多条长短视频打包发布**

- 短视频：抢流量、造情绪、测哪条 Hook 能爆  
- 长视频：同主题加深、建专业感与信任  
- 素材复用：同一热点只调研一次，Shorts 切片 + Long 扩写  

```
        ┌─────────────────────────────────────┐
        │         套餐 · 例如 OpenAI IPO       │
        └─────────────────────────────────────┘
              │           │           │
         Short ①      Short ②      Long ①
         讨论型        展望型        讨论为主
         30s          25s          8min
              └───────────┴───────────┘
                    共用：Hook 素材、B-roll、口播语气
                    片尾：每条各自最后 5 秒 Wenap
```

## 三、套餐规格（三档）

按热点大小选档；**默认用 M 标准套餐**。

| 档位 | 组成 | 总工作量 | 适用 |
|------|------|:--------:|------|
| **S 轻套餐** | 2 Shorts | 低 | 小热点、试选题、周中填空 |
| **M 标准套餐** | 3 Shorts + 1 Long | 中 | **常规每周 1 主题** |
| **L 重套餐** | 5 Shorts + 1 Long | 高 | OpenAI IPO、NVDA 大事件等 |

**发布节奏建议（M 档）：**

| 天 | 动作 |
|:--:|------|
| D0 | 发 Short ①（讨论型，最强 Hook） |
| D1–2 | 发 Short ②（解释型或展望型） |
| D3 | 发 Short ③（与 ① 角度不同，防审美疲劳） |
| D5–7 | 发 Long（把三条 Short 里表现最好的扩成 6–12min） |
| 之后 | Long 再切 1–2 条 Shorts 二次分发（可选） |

TikTok 与 YouTube Shorts **同源竖屏**；Long 仅 YouTube 横屏 16:9（或竖屏实验版）。

## 四、M 标准套餐 · 固定配方

每个主题按下面 **4 条** 做；主型号已标注，发布顺序可调。

| # | 形态 | 时长 | 主型号 | 制作模式 | 作用 |
|---|------|------|--------|----------|------|
| **①** | Short | 25–35s | **讨论型** | 视频鬼（全 AI B-roll）或 讨论截图版 | 最强 Hook，抢首发 |
| **②** | Short | 20–30s | **解释型** | 视频鬼 | 降低门槛，「这到底是什么」 |
| **③** | Short | 25–40s | **展望型** | 视频鬼 | 频道差异化，世界观 |
| **④** | Long | 6–12min | **讨论型** 为主 | 口播 + B-roll + 可选 Wenap 截图插入 | 信任、搜索、完播 |

**掺配规则（单条内部，非整套餐比例）：**

- ① 讨论为主，可掺 10% 展望（「若成真意味着…」）  
- ② 解释为主，可掺 15% 讨论（「所以资本圈在争…」）  
- ③ 展望为主，可掺 10% 解释（「先搞懂 IPO 是什么」）  
- ④ Long：讨论 50% + 解释 25% + 展望 25%，**片尾仍只 5 秒广告**

## 五、时长与时间轴（Short vs Long）

### Short（总时长含片尾 5 秒）

| 总时长 | 内容段 | 广告段 |
|--------|--------|--------|
| 30s | 0:00–0:25 | **0:25–0:30** |
| 35s | 0:00–0:30 | **0:30–0:35** |
| 40s | 0:00–0:35 | **0:35–0:40** |

**Short 结构（内容段内）：**

1. **0–3s** Hook（大字字幕 + cinematic 画面）  
2. **3s–结束前 2s** 信息/观点冲击（快切、数据流、hologram、股票图）  
3. **结束前 2s** 情绪一句收束（仍零产品）  
4. **最后 5s** Wenap 片尾  

### Long（6–12min，片尾仍 5 秒）

| 段落 | 时长 | 内容 |
|------|------|------|
| 1 Hook | 0:00–0:45 | 同 Short ① 可扩写 |
| 2 背景 | 0:45–2:30 | 发生了什么 |
| 3 深层逻辑 | 2:30–5:00 | 资本 / 技术 / 结构 |
| 4 社会与资本影响 | 5:00–7:00 | 争议、谁赢谁输 |
| 5 未来展望 | 7:00–9:30 | 2030 场景、AI 金融变化 |
| 6 收束 | 9:30–(总长-5s) | 观察者总结，**零产品** |
| 7 片尾 | **最后 5s** | Wenap C 或 B 档 |

讨论型 Long 若插入 Wenap 截图：**放在第 3–4 段当「研究者视角」**，不算广告；广告仍仅最后 5 秒。

## 六、视觉与 AI 工作流（套餐级一次定调）

**同一套餐共用一套视觉关键词**（Veo / Kling prompt 只写一次）：

```
cinematic, futuristic, financial, AI, dark atmosphere, documentary, high-tech,
hologram, stock charts, data streams, AI UI overlays, night city, deep background,
white bold subtitles, slow camera movement
```

| 步骤 | 工具 | 套餐内复用 |
|------|------|------------|
| 方向 + 套餐清单 | ChatGPT / Cursor | 一次 |
| 脚本 | ChatGPT | Short ×3 + Long ×1 |
| 画面 | Veo / Kling | **同一套 B-roll 素材池** |
| 配音 | ElevenLabs | 同一声线 |
| 剪辑 + 白字幕 | CapCut | 每条独立时间轴 |
| 讨论型截图 | Wenap App | 仅 ① 或 Long 可选 |
| 缩略图 | Canva | Long 1 张 + Short 可纯帧 |

**制作模式对照：**

| 模式 | 文档 | 何时用 |
|------|------|--------|
| 视频鬼（全 AI） | `WENAP-视频鬼-流量片模板.md` | 解释型、展望型、讨论型无截图 |
| 讨论截图版 | `WENAP-NVDA讨论-本期填空.txt` + 素材包 | 讨论型 + 有 ticker + 要 Wenap 报告画面 |
| Long 混剪 | 本文 §五 + 视频鬼 B-roll | 标准套餐第 ④ 条 |

## 八、热点 → 推荐套餐映射

| 热点类型 | 建议档位 | 套餐主型号 | Short ① 角度 |
|----------|----------|------------|--------------|
| 具体股大新闻（NVDA、PLTR） | M 或 L | 讨论型 | 「这意味着什么」+ 可选截图版 |
| IPO / pre-IPO 传闻 | L | 讨论型 | 资本结构会变吗 |
| 纯概念（AI 对冲基金、自主投资） | M | 解释型 | 「这到底是什么」 |
| 未来场景（人类分析师消失？） | M | 展望型 | 「If … everything changes」 |
| 小跟进 / 周中填空 | S | 任意 | 单 Hook 快评 |

**避免：** 娱乐八卦、与 AI/金融/未来无关的杂乱热点。

## 九、召唤 AI（与其他「鬼」并列）

```
套餐 + OpenAI IPO
套餐 + NVDA Computex
套餐 + AI hedge funds
套餐 S + Palantir 政府合同
套餐 L + Anthropic pre-IPO
```

**AI 必须交付：**

1. 档位建议（S/M/L）+ 理由  
2. 填好的 §七 填空表  
3. Short ①②③ 中/英口播全文（含最后 5 秒片尾文案）  
4. Long ④ 章节大纲 + Hook 段口播  
5. 共用 Veo/Kling 视觉 prompt 一段  
6. 各平台标题各 1 条  
7. 若 ticker 在 sample 列表 → 片尾可写 `wenap.app/sample/{TICKER}`  

**不要：** 在中间段落插产品功能介绍；**不要** 片尾超过 5 秒。

## 十、频道长期漏斗（不变）

```
Shorts 抢热点 → Long 建信任 → 片尾 5 秒 Wenap → 注册 / 样本页 → 社区与影响力
```

- 冷启动：**M 套餐每周 1 个主题**，Short 先发、Long 跟上  
- 有数据后：爆款 Short 单独升 L 档补发  
- Wenap 永远像 **片尾插播**，不像频道主体
